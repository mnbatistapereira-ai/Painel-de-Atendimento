# 🍔 Hamburgueria Explosão

## 📌 Sobre o projeto

O **Hamburgueria Explosão** é um projeto desenvolvido em HTML, CSS e JavaScript, baseado em um sistema de Painel de Atendimento e adaptado para o ambiente de uma hamburgueria.

O objetivo é apresentar um site de hamburgueria com cardápio, promoções, notícias, agendamentos e gerenciamento de fila de clientes, proporcionando uma experiência simples e organizada para os usuários.

## 🎯 Funcionalidades

O projeto conta com as seguintes funcionalidades:

- **Cardápio:** apresentação dos produtos e respectivos preços.
- **Pesquisa de produtos:** permite procurar hambúrgueres e outros itens do cardápio.
- **Pedidos:** permite adicionar produtos ao contador de pedidos.
- **Gerenciamento de clientes:** cadastro de clientes na fila de atendimento.
- **Atendimento VIP:** clientes VIP possuem prioridade na fila.
- **Chamada de clientes:** permite chamar o próximo cliente e anunciar seu nome por voz.
- **Finalização de atendimento:** registra os clientes atendidos.
- **Agendamentos:** permite cadastrar agendamentos com nome, data e horário.
- **Promoções:** apresentação e cadastro de promoções.
- **Notícias:** espaço para divulgar novidades da hamburgueria.
- **Vídeos:** reprodução automática de vídeos promocionais em sequência.
- **Avaliações:** permite que os clientes avaliem o estabelecimento.
- **Unidades:** apresentação das unidades, endereços, telefones e horários de funcionamento.
- **Idiomas:** opção de tradução de alguns elementos da página.
- **Armazenamento local:** utilização do LocalStorage para manter informações salvas no navegador.

## 🚀 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Extraia os arquivos, caso tenha baixado um arquivo compactado.
3. Abra a pasta do projeto.
4. Execute o arquivo `index.html` em um navegador.
5. Pronto! O site estará disponível para utilização.

## 🎨 Identidade visual

O site utiliza uma identidade visual baseada em tons de roxo escuro e azul claro, buscando transmitir modernidade e destacar os elementos interativos.

A organização visual foi inspirada em grandes plataformas de comércio eletrônico, utilizando seções bem definidas para facilitar a navegação.

## ⚠️ Observações

- Os dados armazenados pelo LocalStorage ficam salvos no navegador e dispositivo utilizados.
- O contador de pedidos é demonstrativo e não representa um sistema completo de compras.
- Os endereços, telefones e horários das unidades podem ser substituídos pelas informações reais da empresa.
- O funcionamento do site depende dos arquivos HTML, CSS, JavaScript e das mídias utilizadas no projeto.
